# 저장한 초기화 자세로 복귀

`nero_read_status.py`는 현재 플랜지 XYZ를 베이스 좌표계의 mm로, 방향 RPY를 도 단위로 표시합니다. 플랜지는 도구 장착면이며 도구 끝(TCP) 위치와는 다릅니다. 전체 플랜지 피드백이 최신일 때만 좌표를 표시합니다.

2026-11-16 실제 로봇에서 조회하여 `nero_home_position.json`에 저장한 초기화 위치:

- XYZ(mm): **-7.640, -34.287, 715.568**
- RPY(deg): **117.144, -83.364, 13.350**
- J1~J7(deg): **37.000, 5.021, 1.623, -4.818, 1.710, -3.169, -6.107**

모터 7개가 꺼진 상태에서 조회·저장했습니다. 저장 시 0.5초 동안 갱신되는 관절/플랜지 피드백으로 자세가 정지해 있는지 확인합니다. 원점 보정이나 컨트롤러 reset이 아니라 사용자가 정한 복귀 자세입니다.

```powershell
python nero_read_status.py
python nero_home.py             # 저장된 목표와 현재 위치 비교 (이동 없음)
python nero_home.py --execute   # 실제 복귀
```

복귀는 XYZ만으로 관절 자세를 다시 계산하지 않고 저장된 관절각 7개를 사용하여 방향과 관절 배치도 함께 복원합니다. 기존 관절 동시 이동 함수를 속도 5%로 사용합니다. 플랜지 경로는 직선이 아니며 장애물 회피를 하지 않습니다. 팔과 도구의 이동 공간을 확보하세요.

실제 이동에는 모터 7개 활성화, 일반 CAN 위치 제어, 최신 피드백과 이동 전 정지 검사가 필요합니다. 자동 enable/disable/reset은 하지 않습니다. 모터가 꺼져 있다면 기존 활성화 절차를 먼저 수행하세요. 이미 초기화 자세라면 목표를 보내지 않습니다.

기본 관절 이동 한도는 관절별 100도입니다. 한도를 넘어야 하는 경우 먼저 미리보기로 차이를 확인하고 `--max-joint-move-deg`를 지정할 수 있습니다(최대 180). `--timeout`은 목표에 가까워지지 않는 시간 한도이며 기본 60초입니다. 도착 시 저장한 플랜지 위치(2mm 미만)와 방향(1도 미만)도 확인합니다. 통신 소실·이동 실패·사용자 중단의 처리는 기존 공용 이동 함수의 급정지 정책을 따릅니다. 진단 로그는 `data/nero_command_logs`에 저장됩니다.

다른 초기화 위치가 필요하면 별도 파일로 저장하고 해당 파일을 지정해 복귀합니다. 기존 파일은 덮어쓰지 않습니다.

```powershell
python nero_home.py --save-current --position another_home.json
python nero_home.py --position another_home.json
python nero_home.py --position another_home.json --execute
```

기본 위치 파일은 실행한 작업 폴더와 관계없이 `nero_home.py` 옆의 `nero_home_position.json`입니다. 위치 파일의 좌표계와 단위는 베이스/플랜지, m/rad이며 임의로 mm/deg 값을 넣으면 안 됩니다.

실물에서는 상태 조회·초기화 위치 저장·미리보기만 수행했습니다. 실제 복귀 이동은 수행하지 않았고, 전송 및 실패 처리는 가상 CAN으로 검증합니다.
